🔄 OUTER LOOP: Goal & Follow-up Sequencer (while true)

Responsibility: Keeps the agent alive across multi-phase tasks. Only triggers when the agent finishes its current work and would otherwise go to sleep.

⚡ INNER LOOP: Immediate Tool Turn & Reflex (while hasMoreToolCalls)

Responsibility: The atomic cycle. LLM thinking ➔ Tool execution ➔ Result ingestion. Repeats until all file operations and commands are settled.

1. The Stateless Illusion

LLMs have zero working memory. The agent reconstructs the entire illusion of memory by injecting previous user turns and tool results as a single concatenated prompt on every turn.

2. Truncation Guard

If an LLM hits the max-output token limit mid-JSON, Pi's engine refuses to execute the half-generated tool call to prevent corrupted files on disk.

3. Automatic Compaction

When the transcript approaches 80% of the token limit, the agent triggers a silent background summarizer to compress past turns into a concise briefing.
